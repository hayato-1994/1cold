4. 問1〜問5 記述・計算問題の必須公式
【問1・問2：冷凍サイクル】
・実際吐出し比エンタルピー：h'2 ＝ h1 ＋ (h2 － h1) / (ηc・ηm)
・一段膨張中間冷却器熱収支：qmro{(h5 － h7) ＋ (h'2 － h3)} ＝ q'mro(h3 － h6)
・最適中間圧力：pm ＝ √(pk・po) ／ 質量流量：qmr ＝ (V・ηv) / (3600・v)
【問3：伝熱計算】
・多層平板パネル：1/K ＝ 1/αa ＋ Σ(δi/λi) ＋ 1/αr
・着霜蒸発器：1/K' ＝ 1/αa ＋ δ霜/λ霜 ＋ m/αr ／ 水冷凝縮器：1/K ＝ 1/αr ＋ m(1/αw ＋ f)
・円筒配管熱伝導：Φ ＝ 2πLλ(t外 － t内) / ln(D外 / D内)
【問5：圧力容器強度（SM400B：σa＝100 N/mm²、屋外 α＝1 mm）】
・円筒胴必要板厚：ta ＝ P・Di / (2σa・η － 1.2P) ＋ α （板厚は切上げ、最大内径Diは切捨て）
・鏡板必要板厚：ta ＝ P・R・W / (2σa・η － 0.2P) ＋ α （半球形は W＝1, R＝Di/2）
・誘起応力（円筒接線）：σt ＝ P・Di / (2・ta) ／ 長手方向：σl ＝ P・Di / (4・ta) ＝ σt / 2
